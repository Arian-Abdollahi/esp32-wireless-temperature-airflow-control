# Project provenance and editorial approach

This repository contains source code supplied by the project authors and selected photographs extracted without alteration from the original technical report. The publicly presented title and documentation describe the device itself rather than how or where it was developed.

**Included:** the original Arduino sketch (kept byte-for-byte), selected photographs of hardware/LED states and Bluetooth terminal sessions, engineering notes and static code checks.

**Not included:** the original 13-page report or five-page project specification, because those documents contain background material beyond the product-focused repository description. Retain the source documents in a private archival backup if provenance is needed later.

No novel experimental claims, firmware recompilation, Wi-Fi connectivity, cloud integration, performance benchmarks, or validated safety guarantees were added. The implementation remains a prototype demonstration.
