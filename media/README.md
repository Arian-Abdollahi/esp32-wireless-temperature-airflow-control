# Prototype evidence

The files in this directory are selected photos and Bluetooth terminal logs extracted from the original technical report. They are evidence of the prototype demonstration, **not** fresh measurements from a newly executed system.

| File | What it depicts |
| --- | --- |
| `led_prototype_idle.jpg` | Breadboard prototype with two LED indicators |
| `led_heating_indicator.jpg` | Red LED as heating-state indication |
| `led_cooling_indicator.jpg` | Green LED as fan/cooling-state indication |
| `bluetooth_temperature_log.jpg` | Bluetooth serial log showing temperatures and setpoint |
| `bluetooth_direction_commands.jpg` | `R`/`L` commands and direction messages |
| `bluetooth_setpoint_updates.jpg` | Numeric Bluetooth setpoint changes |

No complete schematic or hardware verification can be inferred from these photographs alone.
